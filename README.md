# Sunrise Capture

> 화면 캡처, 스크롤 캡처, 다중영역 캡처, 영역 녹화, 이미지 편집을 하나의 작업 흐름으로 사용할 수 있는 Windows 데스크톱 캡처 도구

## 프로그램 소개

**Sunrise Capture v4.0.1**은 보고서 작성, 오류 기록, 업무 매뉴얼 제작, 현장 자료 정리, 프로그램 검토 등 실무에서 필요한 화면 정보를 빠르게 캡처하고 정리하기 위한 Windows 프로그램입니다.

단순한 화면 저장뿐 아니라 **영역 캡처, 반복 캡처, 다중영역 캡처, 스크롤 캡처, 영역 녹화, 이미지 편집, 최근 작업 관리, 비정상 종료 복구**까지 하나의 프로그램에서 처리할 수 있도록 구성되어 있습니다.

각 기능은 필요한 작업만 바로 선택해 사용할 수 있도록 분리되어 있으며, 캡처 결과를 저장하거나 편집하고 다시 활용하는 흐름이 자연스럽게 이어지도록 설계되어 있습니다.

## 주요 기능

### 화면 캡처

- 마우스로 범위를 지정하는 영역 캡처
- 지정한 영역을 유지하면서 반복하는 영역 지정 후 캡처
- 별도 편집 없이 바로 저장하는 JPG 바로 저장
- 전체 화면 캡처
- 활성 창 캡처
- 특정 창 선택 캡처
- 0~30초 지연 캡처
- 다중 모니터 환경의 모니터 선택 캡처

### 다중영역 캡처

- 여러 영역을 한 번에 지정하여 각각 캡처
- 지정 영역 이동 및 크기 조절
- 다중영역 템플릿 저장 및 다시 불러오기
- 출력 해상도 25~400% 설정

### 스크롤 캡처

- 긴 웹페이지나 문서 화면을 이어서 한 장으로 저장
- 고정 헤더 등을 제외하기 위한 고정영역 설정
- 페이지 버튼, 탭, 스크롤바 등을 직접 조작할 수 있는 대상 조작 기능
- 캡처 진행 프레임 수와 결과 높이 표시
- 경과시간 및 정렬 신뢰도 표시
- 현재까지 캡처한 결과를 저장하고 중지
- 출력 해상도 25~400% 설정

### 영역 녹화

- 사용자가 지정한 화면 영역을 MP4로 녹화
- 녹화 품질 프리셋 선택
- 녹화 일시정지 및 계속
- 마우스 클릭 위치 표시 ON/OFF
- 녹화 영역을 가리지 않도록 제어창 위치 자동 조정

### 이미지 편집

- 펜
- 형광펜
- 사각형
- 원·타원
- 선
- 화살표
- 텍스트
- 번호 마커
- 수동 모자이크
- 되돌리기 / 다시실행
- 선택 객체 복제

### 플로우 이미지

캡처한 이미지를 화면 위에 띄워 참고 자료처럼 사용할 수 있습니다.

- 드래그 이동
- 휠 확대·축소
- 원본 크기 복원
- 편집, 복사, 저장
- 항상 위 표시
- 투명도 조절
- 개별 닫기 및 모두 닫기

### 최근 항목 관리

- 최근 캡처 결과 확인
- 파일명·경로 검색
- 저장 파일 / 메모리 캡처 필터
- `Ctrl` / `Shift` 다중선택
- 선택 항목 제거
- 메모리 캡처 일괄 저장
- 열기, 폴더에서 보기, 복사, 편집, 이름 변경

### 비정상 종료 복구

프로그램이 정상적으로 종료되지 않은 경우 복구 가능한 최근 저장 파일과 임시 캡처를 다시 불러올 수 있습니다.

세션 복구 정보에는 작업 상태와 파일 경로만 기록하며 캡처 이미지 픽셀이나 클립보드 내용은 저장하지 않습니다.

## 기본 사용 흐름

```text
캡처 또는 녹화 기능 선택
→ 화면·창·영역 지정
→ 캡처 또는 녹화 실행
→ 필요한 경우 이미지 편집
→ 파일 저장·클립보드 복사·플로우 이미지·최근 항목에서 활용
```
