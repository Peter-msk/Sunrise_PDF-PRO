# Sunrise PDF PRO

**최신 제품 메타데이터 기준: v2.7.1** · Windows 10/11 x64 · 단일 실행파일(EXE)

한글·업무 문서를 PDF로 변환하고, 여러 PDF를 검수·병합·정리하여 제출용 결과물을 준비하는 Sunrise Group의 문서 업무지원 프로그램입니다.

## 1. 프로그램 개요
Sunrise PDF PRO는 한글 문서와 여러 업무 문서를 PDF로 전환하고, 변환 결과를 확인·정리하기 위한 Windows 데스크톱 도구입니다. 문서 변환과 후속 PDF 작업을 하나의 업무 흐름으로 연결하는 데 중점을 둡니다.

## 2. 개발 목적
- 반복적인 문서→PDF 변환과 결과물 확인 과정을 간소화합니다.
- 변환 결과를 검토하고 필요한 PDF 후처리를 연속 수행합니다.
- 여러 파일을 대상으로 하는 실무 작업의 진행상태를 표시합니다.
- 결과물의 위치와 작업 완료 여부를 명확히 확인하도록 합니다.

## 3. 주요 기능
- 지원하는 HWP/HWPX 등 업무 문서의 PDF 변환
- 변환 파일 선택·일괄 작업과 진행상태 확인
- PDF 결과 검수 및 출력 결과 관리
- 여러 PDF의 병합·정리
- 책갈피와 제출용 패키지 구성 지원
- 변환 단계·처리 시간·출력 상태 확인
- 공지사항 및 업데이트 확인

세부 기능은 설치된 버전과 로컬 문서 프로그램·인쇄 환경에 따라 달라질 수 있습니다.

## 4. 실행조건
| 항목 | 조건 |
| --- | --- |
| 운영체제 | Windows 10 또는 Windows 11 |
| 시스템 | 64비트(x64) |
| 배포 형식 | `Sunrise_PDF_PRO.exe` 단일 실행파일 |
| 문서 변환 | 해당 문서를 열 수 있는 한컴 등 관련 프로그램 및 PDF 인쇄 환경이 필요할 수 있음 |
| Python 설치 | 공식 EXE 사용에는 필요 없음 |

외부 문서 프로그램이 필요한 변환은 해당 프로그램이 정상적으로 설치·작동해야 사용할 수 있습니다.

## 5. 실행 및 사용방법
1. [Sunrise PDF PRO 릴리즈 페이지](https://github.com/Peter-msk/Sunrise_PDF-PRO/releases)에서 배포 가능한 버전을 확인합니다.
2. 제공된 정식 실행파일을 내려받아 실행합니다.
3. 변환할 문서를 추가하고 출력 위치와 필요한 설정을 지정합니다.
4. **변환 시작**으로 작업을 실행하고 진행상태를 확인합니다.
5. 완성된 PDF를 열어 내용과 페이지 구성을 검토합니다.
6. 필요에 따라 병합·책갈피·제출 패키지 기능을 사용합니다.
