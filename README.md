# Sunrise PDF PRO

Sunrise Group의 문서 PDF 변환 및 제출용 PDF 정리 프로그램입니다.

## 프로그램 목적

HWP/HWPX 등 업무 문서를 PDF로 변환하고, 여러 PDF의 검수·병합·후처리를 하나의 흐름으로 연결해 반복적인 문서 제출 준비 작업을 줄입니다.

## 지원 운영체제

- Windows 10 / Windows 11 (64비트, x64)
- 일부 변환 기능은 지원 문서를 처리할 수 있는 한컴 등 외부 문서 프로그램과 PDF 출력 환경이 필요할 수 있습니다.

## 개발언어 및 주요 기술

- **개발언어:** Python
- **주요 기술:** Windows 문서 자동화 및 PDF 처리
- **배포 형태:** 단일 Windows 실행파일(EXE)

## 주요 기능

- 지원되는 HWP/HWPX 및 업무 문서의 PDF 변환
- 여러 문서의 일괄 변환과 처리 진행상태 확인
- 출력 PDF 검토 및 변환 결과 관리
- PDF 병합과 정리
- 책갈피 및 제출용 문서 패키지 구성 지원
- 출력 위치, 처리 결과 및 오류 상태 확인
